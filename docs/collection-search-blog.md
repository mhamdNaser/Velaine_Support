# Collections, search and blog

## Collection pages

Collection pages use the **Collection** section.

### Collection banner

| Setting | What it does |
|---|---|
| **Show collection banner** | Shows the collection title at the top, over the collection image if it has one. |
| **Show description in banner** | Adds the collection description to the banner. |
| **Banner height** | **Small**, **Medium** or **Large**. Applies when the collection has an image. |
| **Overlay opacity** | Darkens the image so the text stays readable, 0–90%. |
| **Text alignment** | **Start**, **Center** or **End**. |
| **Show collection description** | Shows the description above the products when the banner is hidden. |

Add a collection image in **Products → Collections → (collection) → Collection image**.

### Product grid

| Setting | What it does |
|---|---|
| **Number of products per page** | 8–48. |
| **Columns on desktop** | 2–6. |
| **Columns on mobile** | 1–2. |
| **Let shoppers change products per row** | Adds a density toggle next to the sort menu: 2, 3 or 4 columns on desktop, 1 or 2 on phones. The choice is saved in the shopper's browser. |
| **Pagination style** | **Page numbers**, **Minimal numbers**, **Previous / next**, **Load more button** or **Infinite scroll**. |

Shoppers can also switch between grid view and list view. Card appearance comes from **Theme settings → Product Card**, **Cards and images** and **Badges**.

### Promo tiles

Add **Promo tile** blocks to the Collection section to place a campaign tile among the products.

| Setting | What it does |
|---|---|
| **Image**, **Heading**, **Text**, **Button label**, **Link** | Tile content. |
| **Position in grid** | The tile appears before this product number on the first page. For example, `3` puts it in the third spot. |
| **Width** | **1 column** or **2 columns**. |

Promo tiles show only on the first page, so they don't move when shoppers filter or go to page 2.

### Filtering and sorting

| Setting | What it does |
|---|---|
| **Enable filtering** | Shows filters. Set up which filters appear in the free **Search & Discovery** app. |
| **Filter layout** | See below. |
| **Enable sorting** | Shows the sort menu. |

| Filter layout | Desktop | Phones |
|---|---|---|
| **Sidebar** | Filters in a column beside the products. | Filters in a drawer. |
| **Drawer** | A **Filters** button opens a drawer. The grid uses the full width. | Filters in a drawer. |
| **Horizontal bar** | Filters in dropdowns in a bar above the products. | Filters in a drawer. |

Filters support price ranges, color swatches and active-filter chips that can be removed one by one. Results update without reloading the page.

### Quick add and quick view

**Theme settings → Product Card → Quick add** and **Theme settings → Cart → Enable quick view** add buttons to every product card. See [Cart and quick view](cart-and-quick-view.md#quick-add).

### Collection list page

The **Collections** section (on the collection list page) shows all collections with **Collections per page**, **Number of columns on desktop**, **Columns on mobile**, **Image ratio**, **Show description**, **Show product count** and **Overlay opacity**.

## Search

### Search suggestions

The search icon in the header opens a search panel. As customers type, it suggests products, collections, pages and articles, with keyboard navigation. Recent searches are listed in the panel, with a **Clear** link.

Options are in **Theme settings → Search**: **Enable search suggestions**, **Number of suggested products**, **Show price in suggestions** and **Show vendor in suggestions**.

### Search results page

The **Search** section has:

| Setting | What it does |
|---|---|
| **Sidebar menu** | A menu shown beside the results. |
| **Number of products per page**, **Columns on desktop**, **Columns on mobile**, **Pagination style** | Same as on collection pages. |
| **Suggested searches** | Terms shown when nothing is found, separated by commas. |
| **Popular collections** | Collections shown when nothing is found. |

Results are split into tabs: **All**, **Products**, **Articles** and **Pages**, each with its number of results. Product results can be filtered and sorted like a collection.

## Blog

The **Blog** section shows a list of articles.

| Setting | What it does |
|---|---|
| **Read more** | Text of the link on each article card. |
| **Blog Post Per Page** | 1–12. |
| **Feature the latest article** | Shows the newest article large, above the others. |
| **Show tag filter** | Adds tag buttons so readers can filter articles by tag. |
| **Show read time** | Shows an estimated reading time on each card. |
| **Columns on desktop** | 1–4. |
| **Pagination style** | **Page numbers**, **Minimal numbers**, **Previous / next**, **Load more button** or **Infinite scroll**. |

To show articles on the home page, use the **Blog posts** section. See [Sections library](sections-library.md#storytelling).

## Articles

The **Main article** section shows a single article.

| Setting | What it does |
|---|---|
| **Display author name**, **Display published date** | Show the author and date. |
| **Show read time** | Shows an estimated reading time. |
| **Show reading progress bar** | A thin bar at the top of the screen fills as the reader scrolls. |
| **Show table of contents** | A list of the article's headings, built automatically. On desktop it stays beside the article and highlights the current heading. |
| **Include subheadings (H3)** | Adds H3 headings to the table of contents. |
| **Show previous and next links** | Links to the previous and next articles. |
| **Show related articles** | Articles that share a tag first, then the latest posts. |
| **Number of related articles** | 2–6. |

The section is built from blocks: **Title**, **Author**, **Published date**, **Thumbnail**, **Content**, **Article excerpt**, **Tags**, **Share buttons** (WhatsApp, Facebook, Twitter, Pinterest, Messenger and Email) and **Comments**. Comments appear when they are turned on for the blog in **Online Store → Blog posts → Manage blogs**.

Use H2 and H3 headings in your articles, so the table of contents has entries.
