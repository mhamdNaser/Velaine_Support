# Languages and RTL

## Included translations

| Language | Storefront | Theme editor |
|---|---|---|
| English | Yes | Yes |
| العربية (Arabic) | Yes | Yes |
| Deutsch (German) | Yes | English |
| Español (Spanish) | Yes | English |
| Français (French) | Yes | English |
| Italiano (Italian) | Yes | English |
| 繁體中文 (Traditional Chinese) | Yes | English |

"Storefront" covers the text customers see, such as buttons, cart messages and accessibility labels. "Theme editor" covers the setting names in **Customize**.

To edit any storefront text, go to **Online Store → Themes → ⋯ → Edit default theme content**.

## Right-to-left languages

Pages switch to right-to-left automatically for Arabic, Hebrew, Persian and Urdu. Layouts, spacing, menus, sliders, drawers and arrows are mirrored for you.

Settings that say **Start** and **End** (for example **Back to top button position**, **Open from** in the mobile menu, or text alignment in sections) follow the reading direction. **Start** is the left side in English and the right side in Arabic.

## Adding a language

1. Go to **Settings → Languages → Add language**.
2. Translate your content with the free **Translate & Adapt** app.
3. Customers can switch language from the header top bar and from the footer (**Footer → Enable language selector**). The selectors appear when the store has more than one published language.

## Selling in several currencies

Turn on **Theme settings → Cards and images → Show currency code** to show prices as `$10.00 USD`. Add the country selector to the footer with **Footer → Enable country selector**.
