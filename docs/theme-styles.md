# Theme styles and colors

## Theme styles

Velaine comes with one style, built for beauty, skincare and fragrance stores.

| Style | Accent | Fonts (body / headings) | Look |
|---|---|---|---|
| **Velaine** | Bronze `#7D5F33` on light, gold `#C2A06A` on black | DM Sans / Cormorant | Black, gold and cream, sharp square buttons and badges, arch-shaped media |

The arch shape is set in **Theme settings → Cards → Media shape**. You can switch it to oval, rounded or square.

## Color schemes

Each style includes four color schemes:

| Scheme | Use |
|---|---|
| Scheme 1 (Cream) | The default page background. |
| Scheme 2 (White) | Product and content sections that need a brighter background. |
| Scheme 3 (Black) | Black sections with gold accents, such as the footer or banners. Also the default **Dark mode color scheme**. |
| Scheme 4 (Sand) | Warm kraft tone for promotions and calls to action. |

Most sections have a **Color scheme** setting. Change a scheme's colors once in **Theme settings → Colors** and every section that uses it updates.

Each scheme has these colors:

| Group | Colors | Used for |
|---|---|---|
| Base | **Background color**, **Primary text color**, **Heading color**, **Border color**, **Shadow color** | The section background, text, headings, dividers and shadows. |
| Accent | **Accent**, **Accent background**, **Text on accent** | Links, badges, sale prices and highlights. Accent background is the soft color behind icons and chips. Keep **Text on accent** readable on the accent color, with a contrast of at least 4.5:1. |
| Primary button | **Primary button text**, **Primary button background**, **Primary button border**, and the same three **on Hover** | Main buttons such as **Add to cart** and **Check out**. |
| Secondary button | **Secondary button text**, **Secondary button background**, **Secondary button border**, and the same three **on Hover** | Secondary buttons such as **View cart**. |
| Inputs | **Input background**, **Input text**, **Input border**, **Input Background on Hover** | Text fields, dropdowns and the quantity selector. |

## Dark mode

Go to **Theme settings → Colors → Dark mode**:

| Option | What happens |
|---|---|
| **Off** | The store always uses its normal color schemes. |
| **Automatic** | The store switches to dark when the visitor's device is set to dark mode. |
| **Automatic with toggle button** | Same as Automatic, plus a round moon button so visitors can switch themselves. Their choice is remembered. |

While dark mode is on, every section uses the **Dark mode color scheme** (Scheme 3 by default). The logo doesn't change in dark mode, so preview the store with your device in dark mode and check that the logo and any images with transparent backgrounds are still easy to see.

## Other design settings

Fonts, button shapes, card styles, badges and animations are all global settings. See [Global settings](global-settings.md).
