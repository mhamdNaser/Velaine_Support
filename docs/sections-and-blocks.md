# Sections and blocks

Pages are built from **sections**, and many sections are built from **blocks**. Add a section with **Add section** in the theme editor, then add, reorder or remove its blocks in the sidebar.

For a description of every section, see the [Sections library](sections-library.md).

## Section groups

| Group | Contains | Where |
|---|---|---|
| Header | Announcement Bar and Header | Top of every page |
| Footer | Footer | Bottom of every page |
| Overlays | Cart drawer, Popup, Age verifier and Cookie banner | Above the page content |

Sections in a group appear on every page, and you only edit them once. The **Overlays** group is at the bottom of the section list in the editor. Popup, Age verifier and Cookie banner can only be added to this group.

## Footer

| Setting | What it does |
|---|---|
| **Color scheme** | Colors of the footer. **Theme settings → Colors → Footer Background Color** sets its background. |
| **Title font**, **Title size** | Style of the column titles. |
| **Bottom image**, **Bottom image width**, **Bottom image link** | An image in the bottom bar, such as a certification logo. |
| **Enable country selector**, **Enable language selector** | Selectors in the bottom bar. They appear when your store has more than one country or language. |
| **Enable follow on shop** | Adds the Shop app **Follow** button. |
| **Show payment methods** | Shows your accepted payment icons. |
| **Desktop spacing**, **Mobile spacing** | Space above and below the footer. |

Footer blocks:

| Block | Use |
|---|---|
| Menu (once) | A menu from **Online Store → Navigation**. **Split menu** spreads the links over columns. |
| Text | A title and text. **Underline style** adds an accent line under the title. |
| Custom HTML | Your own HTML. |
| Customer support (once) | An image, extra text and phone, email and WhatsApp links. The phone and email come from **Settings → Store details**, and the WhatsApp link from **Theme settings → Social Media Icons → WhatsApp URL**. |
| Social media and newsletter (once) | Social icons, the Shop **Follow** button and a newsletter form, with an optional terms checkbox. |

## Popup

The **Popup** section is in the **Overlays** group. Select it in the editor to preview it.

| Setting | What it does |
|---|---|
| **Show after** | Delay in seconds before the popup opens, 0–30. |
| **Show only once per customer** | After a customer closes it, they don't see it again. |
| **Version** | Change this value to show the popup to everyone again, for example for a new campaign. |
| **Image**, **Subheading**, **Heading**, **Text** | The content. |
| **Discount code** | Shows a code with a **Copy** button. |
| **Show email signup form** | Adds an email field. Subscribers are tagged `newsletter`. |
| **Button label**, **Link** | A button, used when the email form is off. |

## The Main section

**Main** is a flexible section that you build from theme blocks. It's in the **Sections** category of **Add section**, and also has ready-made presets: **Rich text**, **Collapsible content** and **Features grid**.

| Setting | What it does |
|---|---|
| **Direction container** | **Column** (blocks stacked), **Row** (side by side) or **Grid**. |
| **Columns on desktop**, **Columns on mobile** | Grid only. |
| **Alignment** | **Start**, **Center** or **End**. |
| **Width** | **Narrow**, **Page** or **Full**. |
| **Space between blocks** | 0–64 px. |
| **Color scheme**, **Background color**, **Vertical padding** | Colors and spacing. |

**Custom section** works the same way, with a **Background** image instead of the layout settings.

## Theme blocks

Theme blocks can be used in **Main** and **Custom section**, in any order. **Row** and **Column** blocks can hold other blocks, so you can nest layouts.

| Block | Settings |
|---|---|
| **Heading** | **Heading**, **HTML tag** (**H2**, **H3** or **Paragraph**), **Heading size**, **Text alignment**, **Use accent color**. |
| **Text** | Rich text with **Text size**, **Text alignment**, **Maximum line length** and **Muted color**. |
| **Plain text block** | Plain text with font size, weight, style, alignment and color. |
| **Button block** (preset **Custom button block**) | **Button text**, **Button link**, size, alignment, padding, margin, **Border radius** and colors. |
| **Image block** (preset **Custom image block**) | **Image**, **Alt text**, width, height, **Image fit**, alignment, border radius and border. |
| **Icon with text** | A built-in **Icon** or **Custom icon image**, a heading and text. **Layout**: **Stacked** or **Side by side**. |
| **Accordion** | Collapsible **Row** blocks. **Open one row at a time** and **Show in a box**. Each row has a **Heading**, **Icon**, **Content** or **Page content**, and **Open by default**. |
| **Product card** | A single **Product**, shown like the cards in collections. |
| **Spacer** | **Height on desktop**, **Height on mobile** and **Show divider line**. |
| **Row** / **Column** | The **Group** block. **Layout direction** (**Horizontal** or **Vertical**), **Alignment**, padding and **Width**. |
| **Apps** | Blocks from apps you install. |

## Tips

- Most sections have a **Color scheme** setting. Alternate schemes (for example Light, then Soft) to separate sections without extra spacing.
- Hide a section on a page with the eye icon instead of deleting it, if you may want it back.
- Every new section comes with a preset, so it looks complete as soon as you add it. Replace the sample text and images with your own.
