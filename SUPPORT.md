# Support policy

## What support covers

- Questions about theme settings, sections and blocks.
- Help setting up features described in the [documentation](docs/README.md).
- Bugs in the theme: broken layouts, dead links, features that don't work as documented.
- Compatibility issues after Shopify platform changes.

## What support doesn't cover

- Customizations or code changes, including CSS or Liquid edits.
- Third-party apps and their integration with the theme.
- Help updating a customized theme to a new version.

These services are not included in the theme price. For custom work, we recommend hiring a [Shopify Partner](https://www.shopify.com/partners/directory).

## Before you edit code

The theme doesn't support code changes. If you edit code anyway, duplicate the theme first in **Online Store → Themes → … → Duplicate**, and work on the copy.

## Response times

- We reply to every request within **2 business days**.
- Critical bugs that stop customers from buying are fixed as soon as they are confirmed, and the fix ships in the next theme update.

## How to contact us

Use the [support form](./#contact). Include your store URL, the theme version (shown under the theme name in **Online Store → Themes**), and screenshots if you can.
